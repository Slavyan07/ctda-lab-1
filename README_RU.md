# LoliLand AI Copilot — голосовой напарник, версия 0.4

Вы управляете персонажем. Copilot разговаривает по-русски, анализирует скриншоты, изучает
рецепты вашей версии LoliLand TechnoMagicRPG и планирует дальнейшие действия. Модов, игрового
ввода, чтения памяти Minecraft и игровых пакетов в программе нет.

## Скачать, установить, запустить

1. Распакуйте **LoliLand_AI_Copilot_Windows.zip** в отдельную папку вне Minecraft/лаунчера.
2. Установите **Python 3.11 x64** с python.org, включив Python Launcher и Add to PATH.
3. Запустите `install.bat`. Для зависимостей нужен Интернет. Git не нужен.
4. Запустите `start.bat`, откройте «Настройки API», выберите OpenAI или compatible, задайте
   vision-модель, HTTPS URL и ключ. «Применить» сохраняет ключ в **Windows Credential Manager**,
   остальные параметры — в `data/settings.json`. Ключи не попадают в этот JSON и журнал.
5. В «Голосовом напарнике» выберите STT/TTS, устройства, режим и нажмите «Применить голосовые настройки».
6. Включите «Русская озвучка» и, когда готовы, «Включить микрофон».

Сразу после установки работает текстовый интерфейс; свободный разговор требует настроенной LLM.
`start.bat --demo` показывает цикл на искусственных снимках без Minecraft и нейросети.

## Разговор во время игры

- **Push-to-Talk**: удерживайте **Ctrl+Alt+F6**, говорите, отпустите. Комбинация меняется в панели.
  Можно удерживать экранную кнопку. Программа читает физическое состояние клавиш, не перехватывает их.
- **Hands-Free**: после включения микрофона VAD выделяет фразы, отбрасывает короткие шумы и ждёт паузу.
- «Перебить» или начало PTT отменяет озвучку. Во время голоса ИИ микрофон не отправляет фразы в STT,
  после голоса есть защита от хвоста эха. Для акустического эха рекомендуются наушники.
  В Hands-Free перебивайте кнопкой/PTT; полноценного акустического AEC нет.
- «Повтори» повторяет последнее сообщение без нового запроса к LLM. Громкость — в верхней панели,
  скорость и голос — во вкладке напарника.
- Обработка разговора независима от анализа кадра. Явная команда паузы прерывает ожидание
  предыдущего диалогового ответа и отменяет текущую операцию планировщика.

«Может, сделаем реактор?» — обсуждение. «Добавь в план строительство склада» — новая задача.
«Смени цель на магию» сохраняет предыдущую цель на паузе. «Вернись к предыдущей цели»,
«Отложи текущую задачу», «Поставь приоритет 80», «Пауза», «Продолжай», «Проверь результат»,
«Я закончил этот крафт» и «Повтори последнюю инструкцию» обрабатываются через Goal Manager.
Сообщение «Я закончил» запрашивает проверку и не подделывает визуальное подтверждение.

Свободные вопросы («почему этот механизм?», «что выгоднее?», «что нужно в ближайший час?»)
получает LLM с текущей целью, планом, последним видимым состоянием, рецептами, ресурсами,
предпочтениями и контекстом диалога. При неизвестном рецепте ИИ должен попросить показать NEI.
Записи «Запомни: медь в сундуке справа» сохраняются как слова пользователя, а не как факт изображения.
Исправления и договорённости сохраняются отдельно от предположений модели.

## Речь и производительность

| Задача | Вариант |
|---|---|
| Свободный диалог и планирование | Облачная vision LLM, OpenAI / OpenAI-compatible |
| Распознавание | Cloud STT, совместимый с `/audio/transcriptions`, русский язык |
| Локальное распознавание | `install_local_stt.bat`, затем `local`, multilingual `tiny`/`base`, CPU int8, 2 потока |
| Озвучка без облачного TTS | `system`: установленный русский голос Windows через Qt |
| Естественный облачный голос | `cloud`: `/audio/speech`, WAV; по умолчанию `gpt-4o-mini-tts`, `coral` |
| Выбор выхода | В приложении для cloud TTS; system использует выход Windows, меняется в микшере Windows |

Локальная модель **не включена в ZIP** и не скачивается установщиком. Первая загрузка разрешается
отдельным флажком в панели: tiny около 75 MB, base около 145 MB; зависимости занимают больше.
Whisper работает в собственном процессе, повторно использует модель и освобождает память при
отключении микрофона/закрытии. GPU остаётся Minecraft. Большая локальная LLM не запускается.

Микрофон по умолчанию выключен. Аудио хранится только в ограниченных очередях памяти, одна фраза
не длиннее 20 секунд. Cloud STT передаёт аудио, cloud TTS — текст провайдеру. Совместимый сервер
должен поддерживать соответствующие аудио-endpoint: одной поддержки vision недостаточно.
Если отдельный ключ речи пуст, ключ LLM используется только для того же hostname.

Внизу показан расход **LLM** при доступном usage. STT/TTS могут оплачиваться отдельно и в этот
счётчик не входят. При сбое сервиса текстовый режим и прогресс сохраняются.

## Экран, план и память

Выберите «Наблюдать окно», задайте главную цель и нажмите «Начать / Продолжить».
После кнопки захвата есть 3 секунды для возврата в игру. F9 проверяет кадр при активном окне Minecraft,
F8 ставит цель на паузу, F10 повторяет сообщение. Проверьте свободные сочетания в своей сборке:
Copilot не блокирует обработку этих физических нажатий игрой. При конфликте используйте кнопки
или измените PTT на незанятую комбинацию с модификаторами.

Каждая игровая инструкция — одно действие. Новый кадр проверяет результат; неоднозначность
вызывает уточнение или отдельное ручное подтверждение через «Готово». Пропуск не завершает задачу.
План автоматически получает следующий этап, сохраняя подтверждённые и отложенные задачи.
Неизвестные рецепты/технологии остаются блокерами, рецепты стандартных модов не подставляются.

SQLite хранит цели, шаги, разговоры, заметки, рецепты, ресурсы, ошибки и подтверждения. В контекст
передаются последние 24 сообщения и ограниченная долговременная сводка. Полная история остаётся в БД.
Изображения, сообщения пользователя, предположения и сводки имеют разные источники достоверности.
Запасы — нижняя граница свежих видимых/явно введённых слотов. Устные сообщения доступны планировщику
как сообщения, но не увеличивают счётчик визуально подтверждённых предметов.

Данные по умолчанию в `data/`; после перезапуска цель на паузе, ожидающая инструкция восстановлена.
Для резервной копии закройте приложение и скопируйте папку `data`. Ключи отдельно в хранилище Windows:
при переносе ZIP на другой компьютер введите их заново.

## Проверка

`check.bat` проверяет зависимости, перечисляет устройства без записи, запускает проверки типов,
lint и тесты. Код возврата 2 — замечания к аудиоустройствам при успешных проверках кода.
`check.bat --ci` явно пропускает физические устройства. Автотесты используют mock-аудио/API,
сохранённые искусственные изображения и настоящий Qt event loop.

**Настоящий LoliLand, микрофон/динамики Windows, Windows Credential Manager и живые платные API
в облаке не проверялись.** Ручная проверка описана в [WINDOWS_SETUP.md](WINDOWS_SETUP.md).

[Архитектура](docs/architecture.md) · [Отчёт проверок](docs/validation.md).
Обновление: распакуйте новый ZIP отдельно и перенесите `data` при закрытом приложении.
Не копируйте `.venv` между версиями: выполните новый `install.bat`.
