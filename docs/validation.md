# Проверки Copilot v0.3

Проверено в облачной Linux-среде на Python 3.11.17 / PySide6 6.12.0.

| Проверка | Результат |
|---|---|
| `QT_QPA_PLATFORM=offscreen .venv/bin/pytest -q` | **94 passed**, exit 0 |
| `mypy src`, strict | Success, 29 source files |
| `ruff check .` / `ruff format --check .` | All checks passed |
| `uv sync --locked --extra dev --python 3.11` / `uv pip check` | 33 установленных пакета согласованы |
| Hash-locked dependencies в отдельном окружении wheel | `uv pip install --require-hashes`, успешно |
| `uv build` | sdist и wheel 0.3.0 |
| Установленный wheel, отдельный процесс Qt | Цель → инструкция → новый кадр от человека → подтверждение → следующая инструкция → нормальное закрытие |
| Headless CLI replay | 2 PNG-кадра, инструкция, отсутствие ложного завершения, exit 0 |
| Содержимое wheel | DEMO assets присутствуют, модулей ввода и `.env` нет |
| Windows `.bat` | ASCII/CRLF и вызовы проверены статически; сами `.bat` здесь не запускались |

Тесты используют сохранённые снимки искусственного Qt-окна (происхождение — fixture manifest),
mock MSS с геометрией окна и mock HTTP. Отдельный тест полного мультимодального пути отправляет
PNG в mock API, получает visual/plan, принимает новый кадр от человека, подтверждает шаг и получает
следующую инструкцию. Это проверка интеграции, а не качества живой модели.

Проверяются восстановление pending после перезапуска без автостарта, раздельные manual/visual
подтверждения, неизменившийся кадр, исправление ошибки, CAPTCHA/staff pause, stale response после
смены revision, редактирование плана без подделки завершений, валидные DAG и пропущенные зависимости.
Расчёты покрывают партии, общий stock и остатки, механизмы, технологии, альтернативные рецепты,
циклы и версии. Запасы проверяются на повтор слотов, неизвестные количества/контейнеры,
устаревание и отсутствие двойного учёта ручных и визуальных данных. UI проходит настоящий Qt event
loop с worker; TTS управление проверяется через fake backend. AST-проверка запрещает игровые
вызовы ввода/внедрения/чтения памяти в исходном коде.

**Не проверялись:** реальный LoliLand, настоящий платный/локальный vision API, Windows MSS и DPI
на физическом мониторе, установленный русский голос и аудиоустройство Windows.
GitHub Actions настроен на Ubuntu/Windows, но его удалённый результат здесь не подтверждён.
Для этих возможностей есть [ручная приёмка](acceptance.md).
