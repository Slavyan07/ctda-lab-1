# Windows 11: бесплатный локальный запуск

Целевая машина: RTX 4050 6 GB, RAM 16 GB. Приложение не меняет Minecraft, сборку, лаунчер или их файлы. Игровые действия выполняет человек. Git/GitHub не требуются.

## Установка

1. Распакуйте `LoliLand_AI_Copilot_Windows.zip` в папку с правом записи. Не запускайте из ZIP.
2. Установите [Python 3.11 x64](https://www.python.org/downloads/windows/), включите Launcher и Add to PATH. Microsoft Store alias при необходимости выключите. Установите [Ollama Windows](https://ollama.com/download/windows).
3. Выполните `install.bat`. Он создаёт `.venv`, ставит зафиксированные зависимости с SHA256 и сам проект. faster-whisper и Piper входят в основную установку. Ни одного ключа не нужно. Старый `install_local_stt.bat` оставлен как совместимый дополнительный установщик.
4. Выполните `start_ollama.bat` и оставьте окно открытым. Если порт занят автоматически запущенным Ollama, выйдите из него через трей и повторите. Скрипт задаёт `OLLAMA_NUM_PARALLEL=1`, `OLLAMA_MAX_LOADED_MODELS=1`, `OLLAMA_GPU_OVERHEAD=4294967296`, `OLLAMA_KEEP_ALIVE=0`, loopback `127.0.0.1:11434`. Он не перенастраивает уже работающий сервер.
5. Запустите `download_models.bat`: отдельно выберите Qwen `4b` (основной) или `2b` (облегчённый), затем русский голос Piper Irina. Оценка трафика зависит от актуального тега: несколько GB для Qwen, десятки MB для Piper. Ollama проверяет digest; голос сверяется с SHA256 из метаданных официального репозитория, сохраняется MODEL_CARD. При отказе сети/несовпадении SHA256 установка голоса не считается завершённой.
6. Выполните `start.bat`. «Локальные модели»: `ollama`, установленный `qwen3-vl:4b` либо `qwen3-vl:2b`, URL `http://127.0.0.1:11434/v1`. Внутренний адаптер использует нативные `/api/chat`, `/api/ps`, `/api/generate`, без Bearer-ключей.
7. Во вкладке голоса включите согласие на загрузку Whisper tiny/base при первом распознавании. Загрузка без флажка запрещена. Разрешите приложению доступ к микрофону в «Параметры → Конфиденциальность и безопасность → Микрофон».
8. Выберите устройство, `local` STT и `piper` TTS, примените настройки, включите микрофон и озвучку. Для системного русского голоса можно выбрать бесплатный `system`; он зависит от установленных голосов Windows. Piper не требует русского системного голоса.

## Память и производительность

| Параметр | По умолчанию | Назначение |
|---|---:|---|
| `MODEL` | qwen3-vl:4b | При нехватке памяти выберите 2b |
| `OLLAMA_NUM_GPU` | 0 | CPU; VRAM остаётся игре. Опционально 1–12 слоёв GPU |
| `OLLAMA_NUM_CTX` | 4096 | Для экономии 2048, верхняя граница 8192 |
| `OLLAMA_NUM_PREDICT` | 1200 | Ограничение длины ответа |
| `OLLAMA_THREADS` | 4 | Потоки CPU для Ollama |
| `MAX_MODEL_RAM_MB` | 5120 | Порог оценочного RAM-потребления моделей Ollama |
| `MAX_MODEL_VRAM_MB` | 1536 | Порог GPU-памяти моделей Ollama |
| `MIN_FREE_RAM_MB` | 2048 | Минимум свободной системной RAM перед тяжёлой операцией |
| `UNLOAD_AFTER_REQUEST` | true | Выгрузка Ollama и закрытие Whisper после каждого запроса |
| `LOCAL_IMAGE_MAX_EDGE` | 768 | Уменьшение снимка перед передачей Qwen |
| `WHISPER_MODEL` | tiny | CPU int8, два потока; можно base |
| `REQUEST_TIMEOUT` | 180 | Можно увеличить до 600 для медленного CPU |

Whisper, Ollama и Piper используют общую последовательную очередь в приложении. Микрофон/VAD и интерфейс работают отдельно. Piper запускается в собственном завершаемом процессе, ONNX CPUExecutionProvider, один inference-поток и один inter-op поток; Whisper — отдельный CPU-процесс. Прерывание речи завершает только принадлежащий Copilot процесс.

Это **бюджеты и защитные проверки, а не жёсткие лимиты Windows**. `/api/ps` отражает оценку памяти моделей Ollama, не весь working set ОС; фактическое суммарное потребление игры, драйвера, Qt и ОС может быть больше. Контроль RAM/VRAM во время Ollama выполняется примерно раз в 0.5 секунды; возможен краткий выброс до обнаружения. Не запускайте другие модели в том же Ollama одновременно. Очередь не регулирует сторонние программы.

CPU по умолчанию бережёт VRAM, но ответы могут быть медленными; повторная загрузка тоже занимает время. Начните с 2b, если игра занимает большую часть 16 GB RAM. Уменьшите контекст, разрешение кадра или выделенную игре RAM только в её обычных настройках. Не повышайте бюджет автоматически при ошибке. Аппаратных замеров FPS/задержки на RTX 4050 в облаке не было.

## Экран и управление

Оконный/безрамочный режим предпочтительнее. Выберите нужное окно Minecraft; захват учитывает координаты и DPI Windows. При сворачивании/потере фокуса наблюдение останавливается. Не выбирайте лаунчер вместо игры. Чувствительность мыши и игровые бинды не требуются: Copilot не управляет вводом. F8 — пауза, F9 — наблюдение, F10 — повтор, PTT — Ctrl+Alt+F6 или другая разрешённая комбинация. Античит/CAPTCHA не обходятся, проверку проходит игрок.

При обновлении LoliLand измените `PACK_VERSION`: рецепты и стратегии разных версий не смешиваются. Изображение может содержать слишком мелкий NEI-текст; увеличьте интерфейс игры или `LOCAL_IMAGE_MAX_EDGE`. Скриншот и сообщение игрока — разные источники подтверждения.

## Диагностика и проверка на вашем ПК

- `check.bat` — зависимости, перечисление аудиоустройств, lint, mypy, pytest. Запись не включается. Код 2 означает замечания по физическому аудио. `check.bat --ci` явно пропускает устройства.
- `.venv\Scripts\python.exe -m loliland_agent.local.models status` — сервер Ollama, наличие выбранной модели и файлов Piper; ничего не скачивает. Проверка пакетов/файлов не гарантирует качество модели.
- `ollama ps` — остаточные загруженные модели. Copilot требует подтверждения выгрузки своего запроса; при недоступном сервере её нельзя гарантировать.
- Если Hugging Face недоступен: загрузка Piper/Whisper не завершится, платного резерва нет. Нужен обычный доступ к официальному источнику; проверки TLS/SHA256 не отключаются.
- Невозможно распознать речь без пакета/кэша: текстовый ввод продолжает работать. Ошибки модели не заменяются вымышленным результатом.

Аппаратная приёмка: распознавание русской фразы → голосовая постановка цели → чтение настоящего NEI → одно понятное действие → выполнение человеком → новый кадр → проверка → сохранение/перезапуск. Измерьте память и FPS при работающем Minecraft; начните с CPU/2b. Проверьте Piper в выбранных динамиках, PTT, перебивание, F8, DPI и потерю фокуса.

В данной облачной среде проверены программные контракты и искусственные изображения, не реальная игра/звук Windows. Ollama/Qwen не установлены, настоящие веса речи не загружены: Hugging Face возвращает HTTP 403. Поэтому полная работа локальных моделей на физическом ПК **пока не подтверждена**.
