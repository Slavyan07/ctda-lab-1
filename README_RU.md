# LoliLand AI Copilot — руководство

Copilot запускается отдельно от Minecraft и даёт советы. Никаких модов и автоматических игровых действий. Основной режим бесплатный и локальный: Ollama Qwen3-VL, faster-whisper, Piper, SQLite. Ключи API и аккаунты не требуются.

## Начало работы

1. Распакуйте ZIP в доступную для записи папку, например `C:\LoliLandCopilot`.
2. Установите Python 3.11 x64 и Ollama, запустите `install.bat`.
3. Запустите `start_ollama.bat`. Если Ollama уже занимает порт, закройте его через значок в трее вручную и повторите. Скрипт не завершает чужие процессы.
4. В `download_models.bat` выберите Qwen 4b или 2b, затем отдельно Piper. Это явные запросы на загрузку, учитывайте трафик и условия моделей.
5. Запустите `start.bat`. В «Локальные модели» укажите установленную модель. DEMO запускается через `start.bat --demo` и использует искусственные изображения.
6. Выберите окно игры, укажите актуальную версию сборки и главную цель. Copilot изучит видимое состояние и предложит следующий шаг.

## Голос и разговор

В «Голосовой напарник» выберите `local` для STT, `piper` для TTS, устройства и режим PTT/Hands-Free, нажмите «Применить». Микрофон и озвучка первоначально выключены. Для первого распознавания разрешите загрузку Whisper флажком в панели. `tiny` экономит память; `base` может лучше понимать речь, но тяжелее. После кэширования интернет для распознавания не нужен.

Держите кнопку разговора или `CTRL+ALT+F6`. «Перебить»/PTT останавливает озвучку и отменяет фоновый запрос, освобождая очередь локальных моделей. Автонаблюдение при этом выключается; его можно включить снова. Hands-Free подавляет запись во время речи ИИ, но это простая защита от эха, не акустическое эхоподавление.

Примеры:

- «Смени цель на производство плат» — предыдущая цель сохраняется на паузе.
- «Добавь в план строительство склада», «Отложи текущую задачу», «Поставь приоритет 80».
- «Почему ты выбрал этот путь?», «Может, сначала солнечные панели?», «Найди более эффективный путь» — обсуждение и предложения, без молчаливой смены цели.
- «Предпочитаю пресс» — предпочтение сохраняется и учитывается при выборе сопоставимых доступных рецептов.
- «Исправь рецепт …» с полными ингредиентами и количеством — Ollama формирует исправление конкретного известного рецепта. Неполные сведения требуют уточнения. Старый рецепт остаётся в истории.
- «У меня открыта технология пара», «У меня есть пресс», «Не хватает меди» — сведения игрока об условиях и запасах. Нехватка без точного числа делает прежний снимок запасов неактуальным, затем план пересчитывается.
- «Готово» — запрос проверки нового кадра. При неопределённом изображении доступно отдельное ручное подтверждение; оно сохраняется как сообщение игрока.
- «Пауза», «Продолжай», «Повтори», «Что дальше» — короткие команды распознаются локально без запроса к LLM после STT.

## Планы и знания

Для сформулированной цели Ollama определяет целевой предмет. Детерминированный планировщик рассчитывает количества, партии, остатки, зависимости машин и технологий по рецептам этой версии сборки. Известные альтернативы сравниваются автоматически: блокировки, неподтверждённые ресурсы, предпочтение механизма, число крафтов. Поиск ограничен 128 комбинациями и не гарантирует глобальный оптимум.

Если рецепт/технология неизвестны, следующая задача — получить видимое подтверждение, обычно показать NEI. Непоказанный предмет не считается отсутствующим: запасы — частичные снимки. На экране рецепта должны читаться все ингредиенты и количества. Для ручного импорта есть формы рецептов, фактов и документов; форматы — в `examples/`.

SQLite хранит цели, очередь, инструкции, снимки запасов, рецепты с источниками, процедуры, ошибки, подсказки и диалог. В контекст диалога и планирования попадают найденные по словам записи библиотеки. Поиск локальный, без платных embeddings. Процедуры — только описания и шаги для человека. Многошаговые стратегии передаются LLM как контекст; напрямую подставляется только совместимая одношаговая проверенная процедура с доступными условиями и актуальными рецептами.

Противоречащие количества одного рецепта помечаются как спорные и исключаются из расчёта до исправления. Альтернативные рецепты с разными ингредиентами сохраняются как варианты. Сообщения игрока и предположения ИИ отличаются от визуально подтверждённых сведений.

После проверки сохраняются ожидаемый/наблюдаемый результат, вероятная категория причины и действие для исправления. Сложный результат и исправление анализирует локальная vision LLM; локальный слой сохраняет вывод и контролирует повторы. После трёх неудачных проверок одной семьи действий цель останавливается, в том числе после перезапуска. Для продолжения исправьте рецепт, факты или отредактируйте план. Обычное «Продолжай» не сбрасывает защиту.

## Данные и ограничения

`data/copilot.sqlite3` — память; `data/models/` — голосовые модели; `data/settings.json` — настройки; `data/evidence/`, `data/instructions/` и записи — изображения; `logs/` — локальные журналы. В них могут быть личные сведения с экрана. Архив сборки исключает пользовательские данные, веса и `.env`.

Сначала нужен интернет для Python-пакетов, Ollama и выбранных моделей. После установки и кэширования локальная обработка не требует облачного сервиса. ZIP содержит исходники и установщики, а не готовый EXE или многогигабайтные веса. Без весов доступны интерфейс, память, локальные команды и DEMO; свободный диалог и распознавание не подменяются фиктивными ответами.

Подробные параметры компьютера и честные границы проверки: [WINDOWS_SETUP.md](WINDOWS_SETUP.md), [docs/validation.md](docs/validation.md). Старые облачные адаптеры сохранены для совместимости исходников; `FREE_MODE=true` запрещает их использование и скрывает платные настройки. Автоматического fallback нет.
