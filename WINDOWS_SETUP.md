# Windows 11: установка и проверка голосового Copilot

## 1. Распаковка и установка

Распакуйте `LoliLand_AI_Copilot_Windows.zip`, откройте папку `LoliLand_AI_Copilot`.
Нужен Python **3.11 x64** с python.org, Python Launcher и доступом в Интернет.
Запустите `install.bat`, затем `start.bat`. Установщик проверяет версию/разрядность,
создаёт `.venv`, устанавливает закреплённые зависимости с хэшами, ставит пакет и сохраняет существующий
`.env`. При ошибке окно показывает русское пояснение и ждёт нажатия клавиши.
Git и изменения Minecraft не требуются. Папка с кириллицей/пробелами поддерживается цитированием путей.

Проверка без игры: `start.bat --demo`. «Начать» → инструкция инвентаря → «Наблюдение» →
«Человек: показать следующий демонстрационный кадр» → «Проверить». DEMO не использует нейросеть.
Свободный диалог даже в DEMO требует настроенного LLM API; вместо нейросети не подставляются
заранее записанные разговоры.

## 2. Безопасная настройка API

«Настройки API»: provider `openai`, URL `https://api.openai.com/v1`, подходящая vision-модель
(по умолчанию `gpt-4.1-mini`) и ваш ключ LLM. Для другого сервиса — `compatible` и его HTTPS `/v1` URL.
Заполните точную версию сборки. «Применить» сохраняет ключ через Windows Credential Manager,
неключевые параметры — `data/settings.json`. На другом компьютере ключ нужно ввести заново.
При недоступности хранилища программа объяснит, что настройки действуют только в текущем сеансе.
Пароль игрового аккаунта не нужен.

`.env.example` содержит все параметры. `.env` можно настроить вручную; такой ключ хранится в нём
открытым текстом, поэтому предпочтительнее GUI + хранилище Windows. Загружаются `.env`, затем сохранённые
GUI-параметры, а явно заданные переменные процесса имеют наивысший приоритет. Реальные ключи,
данные пользователя, `.env` и хранилища Windows никогда не включаются сборщиком в ZIP.
Если вручную оставлен `PROVIDER=offline` в переменной процесса, GUI не сможет заменить эту переменную
для следующего запуска, пока вы её не уберёте.

OpenAI-compatible означает поддержку Chat Completions JSON/image_url. Для речи отдельно нужна
совместимость `/audio/transcriptions` и `/audio/speech`. Сервис может поддерживать лишь часть функций.
Текст/скриншоты/аудио передаются выбранному сервису; модели и тарификация выбираются вами.
LLM-счётчик не учитывает плату STT/TTS.

## 3. Микрофон и распознавание

Windows → Параметры → Конфиденциальность и безопасность → Микрофон:
разрешите доступ классическим приложениям. Подключите микрофон до запуска/обновления устройств.
Вкладка «Голосовой напарник» → «Обновить устройства» → выберите микрофон.

Для облака: STT=`cloud`, `Speech API URL=https://api.openai.com/v1`, модель `gpt-4o-mini-transcribe`.
Введите ключ речи, либо оставьте его пустым для использования ключа LLM того же hostname.
«Применить голосовые настройки», затем «Включить микрофон». Это явное включение записи;
приложение не восстанавливает включённый микрофон автоматически после перезапуска.

PTT: режим `ptt`, удерживайте `CTRL+ALT+F6`, говорите, отпустите. Можно использовать экранную кнопку.
Клавиша настраивается: CTRL/ALT/SHIFT + SPACE/F1..F12, кроме зарезервированных F8/F9/F10.
Выберите свободное сочетание в своей сборке. Copilot не подавляет и не посылает нажатия в игру.
Hands-Free: `hands_free`, VAD с порогом `VAD_THRESHOLD=0.015`, паузой `VAD_SILENCE=0.7` сек.
Настройки порога доступны через `.env`; слишком шумный микрофон даёт ложные фразы, тихий — пропуски.
Фразы короче примерно 300 ms отбрасываются; максимум 20 секунд. Длинную мысль разделите паузами.

«Перебить» или PTT останавливают речь ИИ. Во время его озвучки микрофон не отправляет новые фразы
на распознавание, хвост эха подавляется 400 ms. Это half-duplex, без акустического AEC:
в Hands-Free для прерывания используйте кнопку/PTT. Наушники уменьшают акустическое эхо.

Локальный режим: отдельно запустите `install_local_stt.bat`. Затем `local`, модель `tiny` (русский
язык поддерживается) или `base`. Разрешите первую загрузку флажком, только если согласны на скачивание
с Hugging Face. Нужны `huggingface.co`, `*.huggingface.co`, CDN `*.hf.co`, PyPI для установки зависимостей.
Размер весов примерно 75/145 MB, зависимости могут занимать сотни MB. Без флажка читается только
существующий кэш `data/models`. GPU не используется: CPU int8, два потока, отдельный процесс.
Первая загрузка/первое распознавание медленнее; ошибки и отсутствие extra-пакетов отображаются в панели.
Отключение микрофона/закрытие отменяет работу и завершает только собственный процесс Whisper.

## 4. Голос ИИ и выход звука

`system`: установите русский пакет речи Windows: Время и язык → Язык и регион → Русский →
Параметры языка → Речь. Перезапустите Copilot. Выберите доступный русский голос.
Это локальный Qt/Windows TTS без передачи текста в speech API. Звук идёт на выход Windows;
индивидуальный выход приложения задаётся через системный микшер громкости.

`cloud`: модель по умолчанию `gpt-4o-mini-tts`, голос `coral`; доступны варианты в списке.
После переключения движка нажмите «Применить», затем выберите голос из обновлённого списка
и примените снова. Выход выбирается в приложении, WAV воспроизводится через QtMultimedia.

Включите верхний переключатель «Русская озвучка», настройте громкость и скорость (0.5–2).
Проверьте «Повтори» и «Перебить». Ошибка синтеза/вывода оставляет текст доступным.
Если голоса нет, программа пишет причину; отсутствие голоса не должно закрывать приложение.

## 5. Игра, память и диалог

Запустите LoliLand обычным лаунчером. Рекомендуется оконный режим/окно без рамки.
Выберите окно → «Наблюдать окно», введите цель → «Начать / Продолжить», вернитесь в игру за 3 секунды.
F9 проверяет скриншот, F8 — пауза, F10 — повтор, когда игра активна. Для разговора PTT работает в фоне.
Можно использовать второй монитор либо компактную панель поверх игры; на время снимка панель скрывается.
При изменении размера/монитора/DPI выберите окно повторно. Чёрный кадр — попробуйте оконный режим,
отключите перекрывающие оверлеи. Модель не должна выдумывать содержимое невидимых слотов.

Примеры: «Может, займёмся энергией?» — обсуждение; «Добавь в план строительство склада» — изменение.
«Смени цель на магию», «Вернись к предыдущей цели», «Отложи текущую задачу», «Продолжай» и
«Поставь приоритет 80» обновляют панель и SQLite. «Я закончил этот крафт» запускает проверку.
Если кадр неоднозначен, «Готово» предлагает отдельное подтверждение человека.

`data/copilot.sqlite3`: задачи, разговоры, заметки с источниками, рецепты, ресурсы и события.
История сохраняется полностью, в LLM передаётся ограниченный контекст и сводка.
Слова пользователя не становятся визуально подтверждёнными запасами. Рецепты берутся из полного NEI,
точно процитированного документа вашей сборки или явного ручного ввода. Укажите имя сундука перед
показом: безымянный контейнер не прибавляет запасы. При перемещении вещей вручную пометьте запасы
устаревшими. `PACK_VERSION` изолирует рецепты/ресурсы разных обновлений сборки.

После перезапуска цель на паузе, последняя ожидающая инструкция сохранена. Закройте программу перед
резервным копированием всей папки `data`. Для обновления распакуйте новый ZIP в другую папку,
скопируйте данные, повторите `install.bat`; `.venv` не переносите.

## 6. Проверка и неисправности

`check.bat`: проверка Python/пакетов, перечисление устройств без записи, lint/типы/автотесты.
Код 0 — проверки пройдены; 1 — ошибка кода/зависимостей; 2 — код проверен, аудиоустройства требуют внимания.
`check.bat --ci` явно пропускает аппаратные устройства. Для полной проверки вручную:

1. Запишите фразу PTT, затем Hands-Free; сравните распознанный текст с произнесённым.
2. Переключите микрофон, отключите его физически, проверьте понятную ошибку и работу текстового чата.
3. Прослушайте русский голос, смените голос/скорость/громкость/выход, перебейте его.
4. Убедитесь, что ИИ не распознаёт свою речь; используйте наушники.
5. Обсудите вариант, затем дайте прямую команду добавить задачу; только команда меняет план.
6. Во время анализа экрана задайте вопрос голосом; диалог должен работать независимо.
7. Отключите сеть: прогресс остаётся, ошибки видны, текст и локальные команды доступны.
8. Перезапустите приложение и проверьте восстановление диалога/цели и чтение ключей из хранилища Windows.
9. Проверьте реальный NEI/инвентарь/механизм: один шаг → человек выполняет → новый кадр → проверка.
10. Закройте окно с активными запросами/Whisper: приложение должно освободить микрофон и завершиться.

Эти аппаратные проверки Windows, настоящий LoliLand и живые платные API **не выполнялись в облаке**.
Автотесты используют сохранённые искусственные изображения и mock API/аудио.
