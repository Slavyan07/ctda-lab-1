# Настройка Windows 11

## Установка

Нужен Python 3.11 x64 с Python Launcher (`py -3.11 --version`). В папке Copilot выполните
`install.bat`. Он создаст `.venv`, установит зависимости из `requirements-lock.txt` с проверкой
хэшей и сам пакет без повторного разрешения зависимостей, скопирует `.env.example`, если `.env` ещё нет.
Права администратора и изменения Minecraft не требуются. Не размещайте программу внутри папки сборки.

`start.bat --demo` открывает безопасную демонстрацию на сохранённых искусственных изображениях.
Введите цель → «Начать» → «Открой инвентарь» → «Человек: показать следующий демонстрационный кадр» →
«Проверить» → следующий шаг NEI. Демонстрация работает без ключа и без игры.

## Мультимодальная модель

По умолчанию `PROVIDER=offline`: интерфейс и память работают, нейросеть не подключена.
Для реальных игровых снимков настройте `.env`:

```dotenv
PROVIDER=openai
MODEL=gpt-4.1-mini
API_BASE_URL=https://api.openai.com/v1
API_KEY=ваш_ключ_LLM
VISION=true
PACK_VERSION=точная_версия_вашей_сборки
INTERVAL_SECONDS=8
ANALYSIS_CACHE_SECONDS=30
```

Модель должна принимать изображения через Chat Completions `image_url` и возвращать JSON.
Для другого сервиса используйте `PROVIDER=compatible`, его HTTPS `/v1` URL, vision-модель и ключ.
Локальный вариант: `PROVIDER=ollama`, `API_BASE_URL=http://127.0.0.1:11434/v1`,
`MODEL=имя_установленной_vision_модели`, `API_KEY=`. Ollama запускается отдельно; приложение
не скачивает модели. Наличие 6 GB VRAM не гарантирует пригодность любой модели.

Кнопка «Настройки API» меняет параметры текущего сеанса. Для сохранения отредактируйте `.env`.
Никогда не вводите пароль Minecraft. Снимки передаются выбранному провайдеру; уберите из окна
личные сообщения, если не хотите их передавать. Расход токенов виден внизу; цена неизвестна,
пока не заданы реальные `INPUT_PRICE_PER_MILLION` и `OUTPUT_PRICE_PER_MILLION`.

## Игра и панель

1. Запустите Minecraft обычным лаунчером. Рекомендуется оконный режим или окно без рамки.
2. `start.bat` → «Обновить окна» → выберите окно игры → «Наблюдать окно».
3. Введите главную цель. Нажмите «Начать / Продолжить» и вернитесь в Minecraft за три секунды.
4. Выполняйте по одной инструкции. F9 в активном игровом окне запросит проверку без переключения.
   F10 повторит озвучку, F8 поставит Copilot на паузу и остановит речь.
5. «Готово» сначала проверяет кадр. Если доказательств нет, отдельный диалог предлагает ручное
   подтверждение. Оно сохраняется как подтверждение человека. «Пропустить» не закрывает зависимости.

Горячие клавиши могут также обрабатываться самой игрой; при конфликте используйте кнопки на втором
мониторе. Copilot не перехватывает и не отправляет нажатия в Minecraft и не меняет его фокус.
При нажатии кнопки захвата есть задержка 3 секунды для возврата в игру. Закрытое/свёрнутое окно
и потеря фокуса запрещают кадр. В автонаблюдении такие кадры пропускаются.

Для второго монитора перенесите панель вручную. Компактный режим поверх игры скрывает панель на время
захвата, чтобы она не закрывала изображение. Эксклюзивный полноэкранный режим, HDR и сторонние
оверлеи могут давать чёрный/перекрытый кадр — используйте окно и проверьте превью.
MSS использует физические координаты и DPI. При перемещении, изменении размера окна или масштаба
Windows выберите окно повторно. Настройки чувствительности и игровых клавиш не нужны: действия
выполняете вы, подсказки описывают намерение («Открой инвентарь»).

## Рецепты, запасы, цели

Покажите полный рецепт NEI (выход, все компоненты, количества), при необходимости наведите курсор.
Неполные или неуверенно прочитанные рецепты не попадают в KB. Вкладка «Ресурсы и рецепты» позволяет
изучить UTF-8 документ конкретной сборки (до 100000 символов) или явно подтвердить рецепт JSON.
При обновлении сборки задайте другую `PACK_VERSION` и начните новую цель: чужие рецепты и запасы
не смешиваются. Источники сохраняются, но извлечённое моделью всё равно стоит сверять с видимым NEI.

Перед показом сундука впишите уникальное имя хранилища под скриншотом. Неименованные контейнеры
не учитываются. Запасы частичные, срок свежести 5 минут; операции изменения запасов делают их
устаревшими. При самостоятельном перемещении вещей нажмите «Пометить известные ресурсы устаревшими».
Для сложных ситуаций подтвердите данные в редакторе фактов, например:

```json
{
  "base": "x=120 y=64 z=-40",
  "storages": {"металлы": "x=122 y=64 z=-40"},
  "machines": ["Указанный механизм"],
  "technologies": [],
  "raw_resources": ["Медный слиток"],
  "resources": {"inventory": {"Медный слиток": 12}}
}
```

Названия должны совпадать с рецептами; aliases и невидимые запасы не угадываются.
«Изменить план» позволяет редактировать задачи/зависимости/приоритеты, сохраняя подтверждения.
Новая цель ставит предыдущую на паузу. Выберите старую в очереди и нажмите «Начать / Продолжить».
После перезапуска ожидающая инструкция восстанавливается, цель остаётся на паузе.
Достижение главной цели подтверждается отдельной кнопкой человека.

## Русский голос

Windows → Параметры → Время и язык → Язык и регион → Русский → Параметры языка:
установите компонент речи, затем перезапустите Copilot. Qt использует доступные системные TTS-голоса
и выбирает русский. Включите «Русская озвучка», настройте ползунок громкости.
«Повтори» повторяет последнюю инструкцию без запроса API, «Остановить голос» отменяет речь.
Если русский голос недоступен, программа объяснит это и продолжит текстом.
Журнал: вкладка истории, `logs/instructions.txt`; технические события: `logs/copilot.jsonl`.
Голосовое распознавание не требуется и не реализовано.

## Проверка и данные

`check.bat` проверяет зависимости, lint, форматирование, строгие типы и тесты с offscreen Qt.
Автотесты используют сохранённые искусственные снимки, mock захвата и mock API. Они не проверяют
настоящий LoliLand и Windows-аудиоустройство. После установки выполните ручную приёмку
из `docs/acceptance.md` для настоящего MSS и голоса.

Память по умолчанию `data/copilot.sqlite3` (или `DATABASE_PATH`), картинки доказательств и ожидающих
инструкций — соседние `evidence/` и `instructions/`. Для резервной копии закройте программу и
скопируйте всю папку `data`. Не удаляйте PNG ожидающих инструкций между запусками.
API-ошибки не завершают шаг. После трёх ошибок подряд цель ставится на паузу; проверьте модель,
квоты, сеть и настройки, затем продолжите. CAPTCHA и проверки персонала выполняются вручную.
