# Аудит и замена проекта

Выбранный GitHub-репозиторий `Slavyan07/ctda-lab-1`, исходный HEAD
`271afd3c8b95e93476c296cc37517ff0f3649f5e`, содержал MNIST benchmark, notebook и ZIP.
После указания пользователя «заменяй все» содержимое заменяется проектом Copilot в отдельной ветке;
исходные файлы остаются в истории Git. Перед заменой создаётся локальный архив исходного HEAD.

Рабочая заготовка Minecraft Agent v0.2 находилась в `/workspace/loliland-agent` без remote.
В ней уже были внешнее визуальное восприятие, SQLite, DAG, PySide6, HTTP-провайдеры, capture/replay,
но также автоматические контроллеры движения/GUI, исполнитель Windows-ввода, режим LIVE_CONTROL,
калибровка и native input smoke. Они противоречили **последней** задаче Copilot.
Зависимости от Forge Bridge/мода в активном исходном коде v0.2 уже не было; новую такую зависимость
не добавляли. Старое описание перехода через мост заменено текущим аудитом.

| Компонент заготовки | Итог v0.3 |
|---|---|
| `agent.py`, `safety/`, `skills/`, `native_smoke.py` | Удалены; автоматического исполнения больше нет |
| NativeInput, input profile, LIVE_CONTROL, разрешения/калибровка | Удалены из приложения, CLI, настроек и скриптов |
| NavigationController / GUIController | Заменены инструкциями человеку и проверкой результата |
| SQLite/WAL, event/knowledge/usage | Сохранены, расширены версионной памятью целей/рецептов/ресурсов |
| Независимый DAG | Сохранён для валидации зависимостей Goal Manager |
| MSS, Win32 window metadata, PNG/replay | Сохранены как источники только чтения |
| QThread/PySide6 | Перепроектированы в панель Copilot и cancellable worker |
| HTTP-провайдер | Контракты perception/plan/instruct/verify/chat/document с JSON-валидацией |
| Synthetic PNG fixtures | Сохранены как явно искусственные изображения; тестов эмуляции ввода нет |

Добавлены Goal Manager, Recipe Knowledge Base, Resource Tracker, Instruction Engine,
Completion Verifier и системный русский TTS. Тест архитектуры проверяет исходный AST на
запрещённые вызовы ввода, внедрения и чтения памяти. Windows API содержит только чтение окна,
фокуса, DPI и физических уведомительных горячих клавиш. Игровые файлы не открываются.

Старые модули не скрыты за выключенным флагом: их нет в поставляемом пакете.
Существующую v0.2 SQLite можно сохранить: общие таблицы совместимы; новый workspace хранится
в отдельном namespace. Неподтверждённые старые действия/общие записи recipe не превращаются
автоматически в подтверждённые знания Copilot. JSON pending и новые рецепты имеют проверяемые схемы.
