| Проверка | Результат |
|---|---|
| Полный pytest, Qt offscreen | **151 passed** |
| ruff check / format | Успешно |
| mypy src, strict | Успешно, 43 source files |
| Закреплённые зависимости / pip check | Согласованы |
| Windows dependency dry-run, base + local-STT lock | Оба набора разрешаются для Windows, без установки/выполнения Windows-кода |
| uv build | sdist и wheel 0.4.0 |
| Wheel inspection | Голос/диалог/Whisper runner и DEMO assets включены, удалённых игровых input-модулей нет |
| ZIP без Git | Распакован отдельно, зависимости установлены pip с --require-hashes, пакет установлен editable, pip check успешен |
| Отдельный Qt process | Голосовая команда из mock-текста → Goal Manager → обновление панели → нормальное закрытие |
| ZIP integrity | CRC и SHA256 manifest для каждого файла, внешний .zip.sha256 |
| BAT | UTF-8/CRLF, проверка путей/entrypoint; BAT на Windows здесь не исполнялись |

Покрытие: предложение против приказа, защита от ошибочного изменения плана моделью,
локальные явные команды, добавление/смена/отложенные задачи/приоритеты/пауза/возврат к цели,
перезапуск и сохранение диалога, user_report/assumption/provenance, исправления, ограниченный контекст,
сводки от старейших сообщений, ресурсы/рецепты/зависимости, визуальное и ручное подтверждение,
PTT/VAD/тишина/короткие шумы/echo gate/max duration, STT WAV-контракт, cloud TTS WAV-контракт,
ошибки и запрет redirects/утечки ключей, отсутствие микрофона, отмена синтеза,
Whisper CPU/download policy и завершение собственного subprocess, работа диалога во время долгого
зрительного планирования, прерывание долгого диалогового запроса командой паузы, Qt lifecycle,
неизменившиеся PNG, отсутствие игрового ввода, состав ZIP и отсутствие данных пользователя.

Тесты STT/TTS используют mock-адаптеры/API и синтетический PCM. Скриншоты — сохранённые искусственные
кадры (fixture manifest), не Minecraft. Свободный интеллект живой модели не подменяется тестовыми
шаблонами: mock проверяет интеграционный контракт, а не качество нейросети.

В headless Linux выявлено падение нативного Qt PipeWire backend без desktop-конфигурации.
Для offscreen Linux задан PulseAudio fallback, который безопасно сообщает об отсутствии устройств.
На Windows этот обход не применяется. Отсутствие PortAudio/микрофона обрабатывается текстовой ошибкой.

**Не проверено:** физические устройства Windows и качество звука, Windows Credential Manager,
живые STT/TTS/vision API, загрузка/качество настоящей Whisper-модели, реальный LoliLand/NEI,
производительность во время игры на RTX 4050/16 GB. Эти проверки перечислены в WINDOWS_SETUP.md.
