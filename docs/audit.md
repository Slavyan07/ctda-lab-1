# Аудит текущего проекта

Версия до изменения: Copilot 0.4, отдельное приложение с наблюдением, GoalManager/RecipePlanner, SQLite, голосовой панелью, Qt, OpenAI-compatible адаптерами и опциональным локальным Whisper. Исполнителя игровых действий уже не было.

Сохранены экранный захват, DPI/фокус, ручной цикл, GUI, диалог, очередь целей, память, импорт знаний, журнал и записанные искусственные скриншоты. Установочные скрипты и архив не требуют Git.

В 0.5 основной провайдер заменён на нативный Ollama, добавлены Piper, обязательные зависимости локального Whisper/Piper, очередь тяжёлых операций, бюджеты памяти и загрузка моделей по запросу. FREE_MODE по умолчанию запрещает paid/remote inference и cloud speech; старые облачные адаптеры сохраняются только как явно отключаемая совместимость, в бесплатном UI их полей нет. Настройки старого облачного режима при обычном запуске мигрируют на localhost без чтения ключей из Credential Manager.

Добавлены AutomaticCurriculum, SkillLibrary и ReflectionManager. Они интегрированы с действующим Copilot и Conversation Manager. Старые подтверждённые/пользовательские задачи, знания с источниками и различие ручной/визуальной проверки сохраняются. Противоречащие рецепты исключаются из расчёта, явные голосовые исправления проходят через сериализованный actor плана.

AST-тест `test_architecture.py` проверяет отсутствие SendInput, перехвата ввода, чтения/записи памяти процесса и известных библиотек управления. Mineflayer/Forge/Fabric/Bridge не добавлялись. Проверка статистики RAM системы через GlobalMemoryStatusEx не является чтением памяти игры.

Валидация и её границы — [validation.md](validation.md). Автоматической публикации на GitHub нет.
