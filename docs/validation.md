`tests/test_local_learning.py` добавляет 38 тестов к 151 существующему тесту. Проверяются:

- многоэтапные рецепты, партии и DAG, автоматический выбор доступного варианта, нехватка ресурсов и неизвестные технологии;
- предпочтение механизма и приоритет пользовательской задачи;
- смена цели с сохранением предыдущей, восстановление инструкции и библиотеки после перезапуска;
- противоречащие рецепты, исключение спорных данных, явная версия исправления и голосовое применение через actor плана;
- поиск библиотеки SQLite FTS5 и fallback, условия навыка, повторное использование, разделение user_report/verified;
- постоянный счётчик неудач, пауза после лимита, устойчивость к успеху посторонней инструкции;
- нативные Ollama images/JSON schema без Authorization/API-ключа, нулевая стоимость, бюджет памяти, выгрузка, отмена, ошибка неподтверждённой выгрузки;
- последовательная тяжёлая очередь, отмена ожидающего задания, недостаток RAM;
- запрет платных/удалённых настроек и прямого legacy-адаптера в FREE_MODE, миграция старых настроек без чтения ключей;
- загрузка Piper с согласием и SHA256, обнаружение изменённого файла, протокол локального subprocess/WAV;
- CPUExecutionProvider и один поток Piper runner с подменёнными native-моделями;
- завершение собственного Whisper-процесса, предпочтение локального кэша без обращения к сети;
- голосовые сведения о технологиях/машинах/ресурсах, отклонение предложений как подтверждённых фактов;
- запрос ручной проверки главной цели вместо бесконечного повторения завершённой программы;
- завершение headless replay при паузе после лимита ошибок, без бесконечного цикла.

Регрессионные тесты проверяют Qt-панель, PTT/VAD, прерывание, очереди, искусственные записанные PNG, фокус/DPI через mock-окно, ручной игровой цикл, сохранение памяти, отсутствие API игрового ввода/модификации клиента и состав архива. Старые cloud wire-contract тесты выполняются только с явным `free_mode=False` и httpx.MockTransport; сетевые платные API не вызывались.

## Границы доказанного

**Настоящая локальная мультимодальная модель и реальные веса речи не выполнялись.** Ollama отсутствует в cloud, запросы к Hugging Face возвращают HTTP 403. Установка пакетов, CLI Piper и программные протоколы проверены; это не проверка качества Qwen3-VL, распознавания русской речи или качества голоса Irina.

Windows .bat не исполнялись на Linux: проверены содержимое, UTF-8/CRLF и соответствующие Python-команды. Не проверены Windows audio/capture/hotkeys на физических устройствах, настоящий LoliLand/NEI, RTX 4050 6 GB, FPS, фактическая RAM/VRAM и лицензия недоступной карточки голоса. Сборка не содержит EXE/бинарников или весов, не является полностью готовым офлайн-инсталлятором. Первичная загрузка требует сети; последующая обработка использует локальные модели.

Аппаратный проход остаётся по [acceptance.md](acceptance.md) и [WINDOWS_SETUP.md](../WINDOWS_SETUP.md). На GitHub изменения автоматически не публиковались.
