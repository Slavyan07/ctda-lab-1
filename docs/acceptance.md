# Приёмка голосового напарника

Автотесты покрывают искусственные PNG, mock аудио/API, явные команды/предложения,
PTT/VAD/echo gate, память/сводки/исправления, последовательные изменения Goal Manager,
параллельный диалог и зрение, отмену STT/TTS/LLM и завершение собственного Whisper subprocess.
Наличие тестов не подтверждает качество реальной модели или физического звука.

Ручная приёмка Windows: выполните 10 пунктов в конце WINDOWS_SETUP.md.
Обязательно проверить настоящие микрофон/динамики, русский системный голос, выход cloud TTS,
живые API, чтение/запись Credential Manager, DPI/окно Minecraft и реальные рецепты NEI.
Ничего из этого в облачной Linux-среде не отмечено как пройденное.

Git, клонирование и PR не нужны для доставки. Контрольный ZIP должен устанавливаться из
распакованной папки без .git и содержать исходники, GUI, голос, ресурсы, тесты, оба lockfile,
BAT-файлы, README_RU.md, WINDOWS_SETUP.md, .env.example и MANIFEST.sha256.
