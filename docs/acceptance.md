# Приёмка Copilot

## Проверено автоматически в облаке

`check.bat` содержит Windows-эквиваленты команд `ruff`, `mypy`, `pytest`.
Тесты используют сохранённые искусственные PNG, mock MSS/окно и mock HTTP API:

1. GUI: русская цель → инструкция инвентаря → человек меняет входной кадр → проверка → следующая инструкция.
2. Неизменный кадр не завершает шаг; «Готово» предлагает отдельное ручное подтверждение.
3. При перезапуске сохранены pending ID, до-кадр и подтверждённый прогресс; старт только по человеку.
4. Неверное действие даёт одну коррекцию; поздний ответ модели после отмены не применяется.
5. Материалы: количества партий, остатки, общий stock, машины, технологии, циклы, варианты, версия сборки.
6. Слоты: повторное наблюдение не удваивает запас, неизвестные/устаревшие значения не засчитываются.
7. TTS: fake backend проверяет включение/выключение, repeat, cancel, volume без сетевых запросов.

## Выполнить на Windows с настоящим клиентом

Эти пункты **не отмечены как пройденные** в облаке.

1. `install.bat`, `check.bat`, `start.bat --demo`; вручную пройти демонстрационный цикл.
2. Подключить vision API, выбрать реальное окно Minecraft, проверить кадр при масштабе Windows
   100/150/200%, на втором мониторе и после повторного выбора изменённого окна.
3. Подтвердить, что при сворачивании и потере фокуса кадр не принимается; нет активации игры программой.
4. Показать инвентарь, tooltip, полный NEI-рецепт и GUI конкретного механизма. Сверить прочитанные
   названия/количества с экраном. Неполный рецепт должен запросить дополнительный вид.
5. Показать именованное хранилище, переместить ресурсы вручную и проверить свежесть/остатки.
6. Дать конкретную цель/предмет и проверить расчёт по подтверждённым рецептам именно вашей версии.
   Неизвестные зависимости должны оставаться запросами информации, а не выдуманными рецептами.
7. Выполнить одну подсказку; проверить before/after. При неясном результате проверить ручную метку.
8. Проверить F8/F9/F10 при активной игре, второй монитор, компактный режим и скрытие панели на кадре.
9. Включить русский голос; проверить громкость, повтор и отмену. Проверить fallback без русского голоса.
10. Закрыть и перезапустить: цель на паузе, последняя инструкция и план восстановлены.
11. При разрыве сети не должно появляться подтверждение выполненного действия.
12. При CAPTCHA/проверке персонала Copilot должен остановить подсказки и передать ситуацию человеку.

Ни тесты, ни программа не нажимают игровые клавиши. Установка не меняет лаунчер, JAR или моды.
Качество LLM на реальных сложных NEI/механизмах оценивается этими ручными проверками отдельно.
