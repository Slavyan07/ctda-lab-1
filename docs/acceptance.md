# Приёмка на Windows

Автотесты проверяют код с искусственными изображениями, mock-ответами локальных моделей и тестовыми дочерними процессами. Они не заменяют следующий проход на ПК:

1. Установить по WINDOWS_SETUP без ключей и Git, явно загрузить модели, затем отключить интернет.
2. Запустить Minecraft и Copilot; выбрать окно, проверить DPI, сворачивание/фокус и F8.
3. Голосом поставить цель; прочитать настоящий NEI, увидеть обоснованную одну инструкцию.
4. Выполнить действие самому, показать новый экран, проверить подтверждение и причину расхождения.
5. Сообщить о нехватке ресурса, исправить полный рецепт, предложить альтернативу, сменить цель.
6. Проверить, что три повторных неудачи останавливают цель и перезапуск не сбрасывает защиту.
7. Вернуть предыдущую цель, подтвердить шаг, перезапустить и восстановить прогресс.
8. Проверить Piper/Whisper на русской речи, динамики, PTT, Hands-Free и перебивание; измерить RAM/VRAM/FPS с 4b и 2b.

Требуется фактический доступ к моделям при первоначальной установке. В облачной среде HF отвечает HTTP 403; настоящие модели/игра/устройства Windows не проверялись. Эти шаги остаются открытой аппаратной приёмкой.
